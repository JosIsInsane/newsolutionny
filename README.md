# New Solution Home Care — propuesta de rediseño

Maqueta de la página de inicio propuesta para [newsolutionny.com](https://www.newsolutionny.com/), agencia de cuidado en casa (PCA y HHA) en NY, NJ y PA.

> **Maqueta de propuesta, no es el sitio oficial.** Los datos marcados en amarillo (número de licencia, dirección de la oficina y zonas de Pennsylvania) los debe confirmar la agencia.

## Qué incluye

- Versión bilingüe real (ES/EN) sin Google Traductor.
- Formulario "¿Califica tu familiar?" con validación accesible (demo: no envía datos).
- Botones de WhatsApp con mensaje prellenado según el idioma:
  - ES: "Hola New Solution, les escribo desde su sitio web. Me gustaría recibir información sobre el cuidado en casa."
  - EN: "Hi New Solution, I'm writing from your website. I'd like information about home care."
- Barra fija de Llamar / WhatsApp y menú en celular.
- Tipografía Atkinson Hyperlegible, contraste AA, foco visible y soporte de movimiento reducido.

## Cómo verla

Abre `index.html` en el navegador. No necesita instalación.

Para publicarla con GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Estructura

```
index.html   Página completa (HTML + CSS + JS)
assets/      Logo y fotos (tomadas del sitio actual de la agencia)
```
